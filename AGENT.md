# Rankify PDF2CBT — GEM Extraction Prompt (AGENT.md)

> **Purpose:** Instruct the Gemini GEM ( `ishortn.ink/gemini-gem` ) and any fallback AI to extract a **valid `UniversalPaper` JSON** from an educational PDF. This is the *single source of truth* for extraction. The app's parser (`src/lib/parse.ts`), normalizer (`src/lib/normalize.ts`) and validator (`src/lib/validate.ts`) are built around this spec.

---

## 1. What to extract

**Input:** One full question-paper PDF (text, scanned image, mixed, multi-column, with or without answer keys / diagrams / tables).

**Output:** **One JSON *object*** — either full `UniversalPaper` (`{ meta, sections, questions }`) or minimal `{ questions: [] }`. Never a raw array. Never markdown fences. Never explanations outside JSON.

The PDF may contain text-selectable pages, scanned pages (needs vision OCR), multi-column layouts, math, circuits, graphs, tables and figures. Use native vision to read layout, preserve reading order, match diagrams to questions, and find answer keys wherever they appear (end of paper, separate section, last page).

---

## 2. Output schema — `UniversalPaper`

```ts
// Top-level — required keys
{
  meta: { title, exam, language, durationMinutes, totalQuestions, totalMarks, instructions, createdAt, createdBy },
  sections: UniversalSection[],
  questions: UniversalQuestion[]
}

// Also accepted (will be auto-wrapped): { questions: UniversalQuestion[] }
```

### `meta` (required)

| Field | Type | Required | Notes |
|---|---|---|---|
| `title` | `string` | yes | Paper title as printed, e.g. `"SSC CGL 2024 Shift 1"` or source filename. Min 1 char. |
| `durationMinutes` | `integer` | yes | Exam duration. Use printed value, else fallback `180`. `>=1`. |
| `totalQuestions` | `integer` | yes | Must equal `questions.length`. Validator warns if mismatch. |
| `createdAt` | `string` | yes | ISO-8601 `new Date().toISOString()`, e.g. `"2026-05-13T00:00:00.000Z"`. |
| `exam` | `string \| null` | no | Free string — `"SSC"`, `"UPSC"`, `"JEE"`, `"CBSE Class 10"`, `"Custom Test"`. `null` if unknown. **Never** enum-lock. |
| `language` | `string \| null` | no | `"en"`, `"hi"`, `"bilingual"`, `null`. |
| `totalMarks` | `integer \| null` | no | Sum of `marks` if calculable. |
| `instructions` | `string \| null` | no | General instructions block if printed. |
| `createdBy` | `string \| null` | no | Leave `null` unless specified. |

### `sections` (required, may be `[]`)

Flat papers (most): `[]`. Sectioned papers: one entry per section.

```ts
{ id: "sec-physics", name: "Section A — Physics", subject: "Physics", description: null }
{ id: "sec-a",       name: "Part A",               subject: null,      description: "Attempt all" }
```

- `id` — slug, unique.
- `name` — as printed.
- `subject` / `description` — free `string | null`.

### `questions` — `UniversalQuestion[]` (required, `>=1` if any questions exist)

| Field | Type | Required | Notes |
|---|---|---|---|
| `id` | `string` | yes | Stable, e.g. `"q-1"` or `"secA__--__1"`. Autogenerated to `q-{number}` if empty. |
| `number` | `integer` | yes | Display order `1..N`, unique. Duplicate → validation error. |
| `subject` | `string \| null` | yes (nullable) | **FREE STRING** — `"Physics"`, `"Reasoning"`, `"GK"`, `"Maths"`, any language. No vocab lock. `null` if not labeled. |
| `section` | `string \| null` | yes (nullable) | Free — `"A"`, `"Section 1"`, `"Part-A"`. |
| `topic` | `string \| null` | yes (nullable) | Free — `"Kinematics"`, `"Profit-Loss"`. |
| `chapter` | `string \| null` | no | Optional finer group. |
| `type` | `QuestionType` | yes | Lowercase enum — see §3. |
| `text` | `string` | yes | Full question stem. Min 1 char. Preserve LaTeX verbatim — see §4. |
| `textAlt` | `string \| null` | no | Second language (e.g. Hindi) if bilingual paper. |
| `options` | `string[] \| null` | depends | MCQ/MSQ/match/true-false/fill-blank/assertion-reason/passage → `string[] >=2`. NAT/essay → `null`. Single-line each. |
| `answer` | `string` | yes | Encoding depends on type — see §5. `""` if unknown. |
| `answers` | `string[] \| null` | depends | MSQ only — 0-indexed sorted, e.g. `["0","2"]`. Else `null`. |
| `marks` | `number` | yes | Per-question. Default `4` (MCQ) / `4` else. |
| `negativeMarks` | `number` | yes | Default `1` for MCQ-type, `0` for NAT/essay. |
| `hasDiagram` | `boolean` | yes | `true` if question references/contains figure. |
| `diagrams` | `string[] \| null` | yes (nullable) | Data URLs — GEM leaves `null`, manual crop fills it. Do **not** fabricate URLs. |
| `difficulty` | `"easy"\|"medium"\|"hard" \| null` | yes (nullable) | Infer or `null`. |
| `tags` | `string[]` | no | Optional labels. |
| `explanation` | `string \| null` | no | Solution text if printed near answer key. |
| `passageId` | `string \| null` | no | Links passage-type children to parent `id`. |
| `_imageRefs` | `string[]` | no | Temp hint for client — e.g. `["img-1.jpg"]` if diagram detected but not cropped. Leave `[]`/omit if `hasDiagram:false`. |

`subject` / `section` / `topic` / `chapter` are **always free strings** — never constrain to `physics|chemistry|mathematics`.

## 3. Question types — `QuestionType` enum (lowercase)

| Value | When to use |
|---|---|
| `mcq` | **Default.** Single correct, has options. Also use when NAT-like answer is a formula/expression. |
| `msq` | Explicit multi-select (choose 2+). Requires `answers[]`. |
| `nat` | **Only** if answer is a *simple number*: `"42"`, `"3.14"`, `"-5"`, `"0.5"`. Never for formulas. |
| `true-false` | True/False, Yes/No. |
| `fill-blank` | Blank to fill. |
| `match` | Match-the-following / matrix. |
| `assertion-reason` | Assertion & Reason. |
| `passage` | Comprehension parent with `passageId` children. |
| `essay` | Descriptive / long answer. |

**MSM (Match) vs MSQ:** old spec called MSM `match`; new spec keeps `match` type — use it.

**Priority rule:** If the PDF says "answer is `m(R-r)/(M+m)` / `√(2gh)` / `2x+3` / `πr²`" → that is **`mcq`**, never `nat`. Test interface only allows numeric keypad for `nat`.

---

## 4. Math & LaTeX — PRESERVE, DO NOT UNICODE-CONVERT

**Critical — opposite of old instruction.** Our renderer uses KaTeX. **Preserve LaTeX verbatim** inside strings.

- **Inline:** `$...$` and `\(...\)` — keep exactly as seen, e.g. `$x^2 + 2x + 1$`, `$\frac{1}{2}$`, `$\theta = 30^\circ$`
- **Display:** `$$...$$`, `\[...\]`, `\begin{equation}...\end{equation}` — keep block form
- **All LaTeX commands stay:** `\frac`, `\sqrt`, `\theta`, `\int`, `\sum`, `\le`, `\ge`, `\neq`, `\times`, `\alpha` etc.
- **Do NOT** replace with Unicode (`x²`, `√`, `θ`, `∫`). The app's `normalizeText` tokenizes `$...$` blocks and preserves them byte-for-byte.
- Only *plain* text outside math is whitespace-collapsed (`\n{2,} → \n`, runs of spaces → one space, trim lines). Math blocks are untouched.
- Options are **single-line** — the normalizer replaces `\n → space` inside options. Keep `$\sqrt{2gh}$` on one line.

Examples:

```
✅ "Find $x^2 + 2x + 1$ where $x = \\frac{-b \\pm \\sqrt{b^2-4ac}}{2a}$"
✅ "Calculate $\\int x^2 dx$"
✅ "If $\\theta = 30^\\circ$ and $\\sin \\theta = 1/2$"
✅ "(A) $x^2 + y^2 = r^2$"   "(1) $2\\pi\\sqrt{M/K}$"
❌ "Find x² + 2x + 1"               — lost LaTeX, breaks rendering
❌ "Calculate ∫ x² dx"                — Unicode, not LaTeX
```

If the PDF is scanned and OCR is needed, **reconstruct the LaTeX** from what you see — do not leave it as `x2` or `sqrt`.

## 5. Answer encoding — get this exactly right

| Type | `answer` | `answers` | `options` |
|---|---|---|---|
| `mcq` | `"1"`–`"N"` **1-indexed** as displayed (option A = `"1"`). `""` if unknown. | `null` | `["(A) ...", "(B) ..."]` or `["(1) ..."]` — include labels as printed, single-line, LaTeX preserved. |
| `msq` | `""` (must be empty) | `["0","2"]` **0-indexed sorted** (`"0"` = first option). Error if empty. | same as mcq, `>=2` |
| `nat` | `"42"` / `"3.14"` / `"-5"` simple number | `null` | `null` |
| `true-false` | `"1"` or `"2"` matching option order | `null` | `["True","False"]` or as printed |
| `fill-blank` | `"answer text"` | `null` | `null` or `["..."]` if clues exist |
| `match` | `"1"` or `"P"` depending on paper | `null` | `>=2` as printed |
| `assertion-reason` | `"1"`–`"4"` | `null` | standard 4 options |
| `passage` / `essay` | `""` | `null` | `null` |

**Never** put a formula in a `nat` answer. If answer key says `"m(R-r)/(M+m)"` → type is `mcq`, answer is option index, not the formula string.

If no answer key exists in the PDF, set `answer: ""` and `answers: null` and leave `answerKeyFound` logic to the app — do not hallucinate answers.

## 6. Diagrams & figures

- `hasDiagram: true` — only if the stem says **"figure below / circuit shown / graph above / refer to Table 2.1"** or a figure is visually attached to that question.
- `hasDiagram: false` — pure text.
- GEM **does not** output bounding boxes. Set `diagrams: null` and optionally `_imageRefs: ["img-q5-1.jpg"]` as a hint. The user will **manually crop** the real figure from the rendered PDF in `/review` (canvas 1.5×, drag box → dataURL). Validator warns `hasDiagram:true` with no refs but does not block — Review lets the user add crops.
- Do **not** include diagrams from other questions. Be spatially accurate — "above/below this stem, same page".
- If no diagrams, `diagrams: null`, `_imageRefs` omitted or `[]`.

Old spec's `diagrams: [{ pageNumber, boundingBox:{x,y,width,height}, label, type }]` is **deprecated** — do not output.

## 7. Validation (what `src/lib/validate.ts` checks)

Errors **block** (`ok:false` — user must fix/edit in Review):

- `meta.title` empty
- `questions` empty when expected
- `q.text` empty
- Duplicate `q.number`
- `mcq`/`msq`/`match` with `<2` options
- `msq` with `answer !== ""` (must be empty)
- `msq` with empty `answers[]`

Warnings (yellow — allowed to proceed):

- `meta.totalQuestions != questions.length`
- `mcq` answer not in `"1".."N"` range
- `nat` with `options !== null`
- `hasDiagram:true` with no `diagrams`/`_imageRefs`
- Any other soft mismatch

The app's `parsePastedJSON` also: accepts both full `UniversalPaper` and minimal `{ questions: [] }`, auto-fills missing `id/number/marks/negativeMarks/hasDiagram/diagrams/difficulty`, preserves math blocks, collapses whitespace outside them, and extracts JSON from fences (````json` / prose`).

---

## 8. Critical output rules

1. Return a **JSON object** (`{...}`) — not an array, not markdown.
2. Required top keys: `meta`, `sections`, `questions` (or at least `questions` for minimal — app will synthesize `meta`).
3. **Do not wrap** in ````json fences. No prose before/after. The parser strips fences but GEM should return raw JSON starting with `{` and ending with `}`.
4. Valid JSON only — double quotes, no trailing commas, no comments.
5. All strings LaTeX-preserved — if the PDF shows `$...$`, output `$...$`, not Unicode.
6. If no questions found: `{"meta":{"title":"Empty","durationMinutes":180,"totalQuestions":0,"createdAt":"..."},"sections":[],"questions":[]}`
7. `confidence` / `metadata` top-level keys from old spec are **not used** — do not output.
8. Keep reading **accurate** — preserve option labels `(A)`/`(1)` as printed, keep `subject` free-form, infer `section` only if printed.

## 10. Fallback AI (Mistral / Groq / NVIDIA) note

Fallback providers receive only the **first ~15k chars of extracted PDF text** (4 pages) with a system prompt mirroring this spec, and are asked for `response_format: { type: "json_object" }`. Same `UniversalPaper` rules apply. Client auto-parses via `parsePastedJSON` either way.
